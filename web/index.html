Architectural Principles & Boundaries VISIBLE INTELLIGENCE

FRIDAY is designed as a **visible, controllable local assistant** rather than an opaque cloud daemon. Every capability has an explicit privacy boundary:

┌────────────────────────────────────────────────────────────────────────┐ │ FRIDAY LOCAL INTELLIGENCE ARCHITECTURE │ ├────────────────────────────────────────────────────────────────────────┤ │ 1. LOCAL FOUNDATION MODEL: Ollama (gemma2:2b / go1.0) on Apple Silicon │ │ 2. DETERMINISTIC TOOLS: Safe AST Math, Time, System Hardware, Files │ │ 3. PRIVACY GUARANTEE: Zero telemetry retention, strictly opt-in memory │ │ 4. TRUST GATE: Dangerous actions require explicit modal approval │ └────────────────────────────────────────────────────────────────────────┘

• Push-To-Talk: Voice recognition in browser runs exclusively when you hold or press the talk button. No fake always-on background promises.

• Safe Tools: Dangerous destructive operations are blocked or gated by an interactive confirmation prompt before execution.

• Memory Inspection: Memories are stored in local SQLite WAL (`friday.db`). You can review, search, and delete facts anytime.
