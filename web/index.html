FRIDAY

Personal Local AI Assistant

FRIDAY is an autonomous personal AI assistant built from the ground up for on-device local execution. Inspired by futuristic AI systems, it couples local open-weight language models with a deterministic backend orchestrator, pluggable tool suite, dual-tier memory, and responsive vocal interaction.

Core Architectural Principles

  • LLM = Intelligence: The language model reasons and decides intent.
  • Backend = Control: Deterministic FastAPI modules control all system permissions.
  • Tools = Actions: Pluggable tools perform verified actions (search, math, telemetry).
  • Memory = Context: SQLite persistence retains facts across conversation boundaries.
  • Frontend = Experience: Futuristic minimalist HUD engineered for presentation impact.

Technology Stack

FastAPI Python 3.14 WebSockets SQLite (WAL) Ollama Google Gemma 2 Web Speech API Apple Silicon MPS
